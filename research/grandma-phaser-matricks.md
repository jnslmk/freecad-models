# grandMA3 Phasers + MAtricks on Stella octangula

The rig has **276 RGB pixels: 12 electrical edges × 23 pixels**. Use a multistep Phaser for changing Dim/Color values and MAtricks to distribute timing across a deliberately ordered Selection Grid. [Phasers](https://help.malighting.com/grandMA3/2.5/HTML/phaser.html) · [MAtricks](https://help.malighting.com/grandMA3/2.5/HTML/matricks.html)

Open the local [Phaser + MAtricks playground](grandma-pixel-playground.html) in a browser (open the HTML file directly). It is a teaching preview, **not** a grandMA3 show file, fixture patch, console emulator, or DMX output.

## Prepare the actual show

1. In **Patch**, choose or build a fixture type/mode representing the real addressable RGB pixels: 276 individually controllable pixels, either individual fixtures or pixel subfixtures of multi-instance edge fixtures. Give fixtures IDs and patch their actual DMX universe/address/channel layout to match the receiving hardware; no patch addresses or transport settings can be inferred from the sculpture's pixel count alone. A fixture type's geometry can define subfixture grid positions, and the patch can rotate/invert their grid representation. [Add Fixtures to the Show](https://help.malighting.com/grandMA3/2.5/HTML/patch_add_fixtures.html) · [Insert Geometries](https://help.malighting.com/grandMA3/2.5/HTML/ft_insert_geometries.html)
2. Select **pixels/subfixtures**, not only their parent edges. Arrange a **23-column X × 12-row Y Selection Grid**: X follows the first-to-last electrical pixel within each edge, Y follows T1-E1…T1-E6, then T2-E1…T2-E6. In absolute LED indices the six T1 rows are 0–22, 23–45, 46–68, 69–91, 92–114, 115–137; T2 rows are 138–160, 161–183, 184–206, 207–229, 230–252, 253–275. The wiring changes direction between edges: consult the [measured first/last-vertex mapping](../led_profiles/stella/wled/mapping.md), rather than assuming adjacent rows share a physical left-to-right orientation. Grid coordinates are **programming relationships**, not 3D-stage coordinates. [Selection Grid](https://help.malighting.com/grandMA3/2.5/HTML/operate_selection.html)
3. Store this selection/order/grid as a **Group pool** object; optional T1, T2, and edge-subset groups simplify selection. A Group pool object stores fixture selection, selection order, and grid **but no attribute values**. Preserve the intended row/column placement when building or recalling subsets. This pool is distinct from the MAtricks **Group** setting below. [Create New Groups](https://help.malighting.com/grandMA3/2.5/HTML/group_create.html) · [Selection Grid](https://help.malighting.com/grandMA3/2.5/HTML/operate_selection.html)

## Program the motion

- Build a Phaser with **at least two steps** of absolute or relative Dim/Color values; for a hard on/off pulse use Dim 100% then 0%. Each step has a **Width**, measured as a percentage of one beat at the Phaser's **Speed** (for example, 100% each gives two one-beat steps), and a **Transition**, the percentage of *that step's width* spent moving to its new value (0% gives a hard change; 100% spends the whole step transitioning). Speed can be displayed in **BPM**, Hz, or seconds per beat. **Phase** is a per-fixture/per-attribute Phaser layer in **degrees**, offsetting timing across the *whole loop*, not a separate angle on each step. [Phasers](https://help.malighting.com/grandMA3/2.5/HTML/phaser.html)
- MAtricks operates along Selection Grid **X/Y/Z**. The **Phase From/To** layer distributes phase offsets along an axis; **Speed/Fade/Delay From/To** are other available axis layers. **Block=N** makes N consecutive positions act together before advancing; **Group=M** interleaves positions into M alternating groups (positions 1, M+1, … together). These are *different* distribution patterns, and MAtricks Group is **not** a Group pool object. [MAtricks](https://help.malighting.com/grandMA3/2.5/HTML/matricks.html) · [Blocks](https://help.malighting.com/grandMA3/2.5/HTML/matricks_block.html) · [Groups](https://help.malighting.com/grandMA3/2.5/HTML/matricks_group.html)

### Two useful looks

1. **Arbitrary simultaneous edges:** select the desired edge rows/pixels in the stored grid, leaving other edges unselected; use two steps (Dim 100% / 0%), Width 100% each, Transition 0%, and **X Phase From/To 0°→0°, Y Phase From/To 0°→0°**. Every selected pixel pulses in lockstep. Change the selection to combine any edges, not only one tetrahedron. [Phasers](https://help.malighting.com/grandMA3/2.5/HTML/phaser.html) · [MAtricks](https://help.malighting.com/grandMA3/2.5/HTML/matricks.html)
2. **Opposite tetrahedra:** select **all 12 rows in the fixed electrical order**, use the same two hard steps, **X Phase 0°→0°**, **Y Block 6**, **Y Phase 0°→180°**. The six consecutive T1 rows form one phase block and the next six T2 rows the other; half a cycle apart, they alternate. For a progressive edge chase instead, distribute Y Phase 0°→360° across the 12 rows without grouping them into blocks (0° and 360° coincide at the endpoints). These examples depend on that row order and on the stated two-step timing; verify the look against the real patch. [Blocks](https://help.malighting.com/grandMA3/2.5/HTML/matricks_block.html) · [MAtricks](https://help.malighting.com/grandMA3/2.5/HTML/matricks.html) · [Phasers](https://help.malighting.com/grandMA3/2.5/HTML/phaser.html)

Once the look is in the programmer, store it as a **multistep preset** or into a **cue** in a sequence, then assign that sequence to an **executor** for playback. The MAtricks settings can be stored in the MAtricks pool for reuse; if storing a preset, check its **MAtricks** store option. [Create New Presets](https://help.malighting.com/grandMA3/2.5/HTML/presets_create.html) · [Store Cues](https://help.malighting.com/grandMA3/2.5/HTML/cue_store.html) · [Assign Object to an Executor](https://help.malighting.com/grandMA3/2.5/HTML/executor_assign.html) · [MAtricks](https://help.malighting.com/grandMA3/2.5/HTML/matricks.html)

**Preview boundary:** the linked browser playground models the ordered 12 × 23 selection and simplified step/axis-phase behavior only. Real output depends on the fixture type's channels/subfixtures, patch, console playback/store settings, and receiver setup; use grandMA3 and the actual hardware to validate those, not the preview. [Add Fixtures to the Show](https://help.malighting.com/grandMA3/2.5/HTML/patch_add_fixtures.html) · [Selection Grid](https://help.malighting.com/grandMA3/2.5/HTML/operate_selection.html)
