2 · Edit Phaser steps

Width is % of a beat; Transition is % of that step’s width spent moving from the previous step to this one. Zero-width steps are instant; at least one width must be nonzero.

Beats per minute; the step widths set the loop length.

3 · Distribute with MAtricks

Phase From → To is in degrees. Block N joins N consecutive positions; Group M interleaves M groups (not a Group pool). Group 0 turns grouping off. Selected Y rows close gaps before spreading.

For chosen edges together: select them and set both axes’ Phase From/To to 0°. To alternate tetrahedra: All + Y Block 6 + Y Phase 0→180. Y Block 1 + Y Group 2 interleaves odd/even edges instead.
